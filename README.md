# FinanceApp – Frontend

Frontend de **FinanceApp**, una aplicación web de **finanzas personales**, desarrollada con **React 19 + Vite**, enfocada en una experiencia **mobile-first**, con autenticación JWT, manejo de estado global y una arquitectura modular basada en componentes y hooks personalizados.

> ⚠️ Proyecto en fase **MVP / Demo técnico** (no versión productiva final).

---

## 🚀 Stack tecnológico

### Core
- **React 19**
- **Vite**
- **JavaScript (ES6+)**
- **React Router DOM v7**

### UI & UX
- **Tailwind CSS v4**
- **Material UI (MUI)**
- **Headless UI**
- **FontAwesome Icons**


### Estado & lógica
- **Zustand** – estado global
- **Hooks personalizados**
- **Formik + Yup** – formularios y validación

### Internacionalización
- **i18next**
- **react-i18next**
- **Language detector**

### Utilidades
- **Axios** – consumo de API
- **JWT Decode**
- **React Toastify**
- **QR Code Generator**

---

## 📱 Enfoque de diseño

- Diseño **mobile-first**
- Layout tipo app móvil
- Navegación inferior (Bottom Navigation)
- Componentes reutilizables
- UI clara y enfocada en usabilidad

> El diseño desktop es funcional, pero la prioridad del proyecto es la experiencia móvil.
